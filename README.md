# CAIS — Десктопный клиент для GigaChat

Десктопное приложение для взаимодействия с большими языковыми моделями линейки **GigaChat** (Сбер), разработанное на Python с использованием графического фреймворка **Flet** (Material 3).

Клиент сочетает интерфейс по макетам Figma, поддержку потоковой генерации (streaming), модуль голосового ввода, гибкую настройку гиперпараметров генерации и встроенную интеграцию доверенных сертификатов Минцифры РФ для защищенного TLS-соединения.

---

## Возможности

### Чат и инференс
- **Потоковый вывод (Streaming):** Рендеринг ответа модели токен за токеном в реальном времени.
- **Выбор моделей:** Переключение между моделями `GigaChat (Lite)`, `GigaChat-Pro` и `GigaChat-Max` (контекстное окно до 128 000 токенов).
- **Управление сессиями:** Создание независимых диалогов, переключение между ними, переименование и удаление чатов.
- **Локальная персистентность:** Автоматическое сохранение сессий, истории сообщений и параметров в `~/.gigachat_history.json`.

### Голосовой ввод
- Встроенная запись и транскрибация речи с микрофона через связку `SpeechRecognition` и `PyAudio` по нажатию кнопки в поле ввода.

### Настройка параметров генерации
Боковая панель конфигурации модели:
- **Temperature** — регулировка степени случайности/креативности ответов
- **Top-P** — ограничение вероятностного распределения токенов (nucleus sampling)
- **Repetition Penalty** — штраф за повторение лексем
- **Max Tokens** — ограничение максимального числа генерируемых токенов
- **System Prompt** — установка системных инструкций и ролевого контекста

### Безопасность и работа с SSL
- Интегрированный бандл доверенных корневых сертификатов Минцифры РФ (`russian_trusted_ca_bundle.crt`).
- Полноценная верификация SSL без отключения защитных механизмов, в том числе при работе из упакованного бинарного файла (`sys._MEIPASS`).

## Стек технологий

- **Python 3.10+**
- **Flet** — кроссплатформенный UI-фреймворк на базе Flutter / Material 3
- **GigaChat SDK** — официальный асинхронный клиент для работы с API
- **SpeechRecognition & PyAudio** — аудиозахват и распознавание речи
- **PyInstaller** — компиляция в автономный исполняемый файл (`.exe`)

## Установка и запуск

### 1. Клонирование и настройка окружения

```bash
git clone https://github.com/parkhomenko-m/cais
cd cais
python3 -m venv venv

# Активация окружения:
# Linux / macOS:
source venv/bin/activate
# Windows:
venv\Scripts\activate

# Установка зависимостей:
pip install -r requirements.txt
```

> **Примечание для Linux:** Для работы модуля голосового ввода требуется системный пакет PortAudio:
> `sudo apt install portaudio19-dev python3-pyaudio`

### 2. Авторизация и запуск

1. Получите авторизационные данные на портале [GigaChat API (Сбер Салют)](https://developers.sber.ru/portal/products/gigachat-api).
2. Запустите клиент:
   ```bash
   python main.py
   ```
3. При первом входе укажите ключ в окне авторизации. Ключ сохраняется в локальной конфигурации пользователя.

## Сборка в Standalone Executable (.exe)

Для создания автономного исполняемого файла:

```bash
pip install -r requirements-dev.txt
pyinstaller GigaChatClient.spec
```

Готовый бинарный файл сохраняется в каталоге `dist/`.
